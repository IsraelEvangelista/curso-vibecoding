1. **P**lanear - Análise e especificação

3. **E**xecutar - Implementação
4. **V**alidar - Testes e qualidade

   - [DESCRICAO_CURTA] → Descrição curta (1 linha)
   - [DESCRICAO_DETALHADA_DO_PROJETO] → Descrição completa
   - [TIPO_DE_PROJETO] → Ex: aplicação web, API, mobile app
   - [PROPOSITO_PRINCIPAL] → Objetivo principal
   - [OBJETIVO_1] → Primeiro objetivo
   - [DESCRICAO_OBJETIVO_1] → Descrição do objetivo
   - [CATEGORIA_STACK_1] → Ex: Frontend, Backend
   - [TECNOLOGIA_1] → Nome da tecnologia
   - [DESCRICAO_TECNOLOGIA_1] → Descrição da tecnologia
   - [NOME_PROJETO_PASTA] → Nome da pasta do projeto
   - [DIRETORIO_PRINCIPAL] → Principal diretório de código
   - [SUBDIRETORIO_1] → Subdiretório específico
   - [DESCRICAO_SUBDIRETORIO_1] → Descrição do subdiretório
   - [ARQUIVO_PRINCIPAL] → Arquivo principal (index.js, main.py, etc.)
   - [REQUISITO_1] → Primeiro requisito
   - [URL_REPOSITORIO] → URL do repositório
   - [COMANDO_INSTALL_DEPENDENCIAS] → Comando instalar dependências
   - [ARQUIVO_AMBIENTE] → .env, .env.local, etc.
   - [VAR_AMBIENTE_1] → Variável de ambiente
   - [VALOR_VAR_AMBIENTE_1] → Valor da variável
   - [SERVICO_PRINCIPAL] → Banco de dados, API, etc.
   - [LINGUAGEM_EXEMPLO] → SQL, JavaScript, Python, etc.
   - [CODIGO_EXEMPLO_CONFIGURACAO] → Código exemplo
   - [COMANDO_DEV] → Comando desenvolvimento
   - [COMANDO_BUILD] → Comando build
   - [COMANDO_TEST] → Comando testes
   - [LINGUAGEM_PRINCIPAL] → Linguagem principal
   - [TIPO_COMPONENTE] → Componente, classe, função, etc.
   - [CODIGO_ESTRUTURA_EXEMPLO] → Código exemplo
   - [CATEGORIA_IMPORT_1] → Categoria de imports
   - [IMPORT_EXEMPLO_1] → Exemplo de import
   - [PLATAFORMA_DEPLOY_1] → Vercel, Netlify, AWS, etc.
   - [PLATAFORMA_PRINCIPAL] → Plataforma principal de deploy
   - [COMANDO_INSTALL_CLI] → Instalar CLI

   - [DESCRICAO_TESTE_1] → Descrição do tipo de teste

   - [FERRAMENTA_1] → Nome da ferramenta
   - [METRICA_1] → Métrica importante

- **Projetos DevOps:** Foque em infraestrutura, CI/CD, monitoring
- **Projetos de pesquisa:** Foque em metodologia, experimentação
